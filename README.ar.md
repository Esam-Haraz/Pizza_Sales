## 📌 نظرة عامة على المشروع

يقدم هذا المشروع حلاً تحليلياً شاملاً للبيانات الخاصة بمطعم بيتزا تجاري طوال عام 2015. من خلال تقييم مقاييس المبيعات الإجمالية، وفترات الذروة (ساعياً، يومياً، وشهرياً)، وأداء فئات المنتجات، وتفضيلات أحجام البيتزا، يقوم هذا المشروع بتحويل البيانات الأولية للعمليات إلى رؤى تشغيلية قابلة للتنفيذ.

الهدف الأساسي هو مساعدة إدارة المطعم على تحسين إدارة المخزون، وتنظيم جداول عمل الموظفين خلال ساعات الذروة، وتوجيه الاستراتيجيات الترويجية نحو المنتجات الأكثر مبيعاً.

---

## 🎯 مشكلة العمل والأهداف

### 1. سياق العمل

تفتقر إدارة المطعم حالياً إلى رؤية مركزية لأداء المبيعات التاريخية والأنماط التشغيلية. وبدون رؤى قائمة على البيانات، يصبح من الصعب تحسين جدول الموظفين، أو إدارة المخزون بكفاءة، أو اتخاذ قرارات تسويقية مدروسة لتعزيز مبيعات العناصر المنخفضة الأداء.

### 2. أهداف المشروع

يهدف هذا التحليل إلى معالجة هذه التحديات من خلال الإجابة على أسئلة العمل الرئيسية عبر أربعة محاور أساسية:

- **مؤشرات الأداء الرئيسية (KPIs):**
  - قياس الأداء المالي الإجمالي (**إجمالي الإيرادات - Total Revenue**).
  - تقييم متوسط حجم المعاملات وعادات الإنفاق (**متوسط قيمة الطلب - AOV**).
  - تتبع إجمالي حجم الوحدات المباعة (**إجمالي البيتزا المباعة** & **إجمالي الطلبات**).
  - حساب كثافة الطلب (**متوسط عدد البيتزا لكل طلب**).

- **الاتجاهات والمواسم:**
  - **الاتجاه اليومي:** تحديد أيام الذروة للمبيعات على مدار الأسبوع.
  - **الاتجاه الشهري:** تحليل تقلبات حجم الطلبات عبر الشهور/الفصول المختلفة.
  - **الاتجاه الساعي:** تحديد ساعات الذروة التشغيلية خلال اليوم لتحسين توزيع طاقم المطبخ وسير العمل.

- **توزيع الفئات والمنتجات:**
  - **المبيعات حسب الفئة:** حساب المساهمة في الإيرادات عبر الفئات (Classic, Supreme, Chicken, Veggie).
  - **المبيعات حسب الحجم:** تقييم توزيع تفضيلات العملاء حسب الأحجام (S, M, L, XL, XXL).

- **أداء المنتجات (الأعلى والأقل أداءً):**
  - تحديد **أعلى 5** و**أقل 5** أنواع بيتزا تحقيقاً **للإيرادات**.
  - تحديد **أعلى 5** و**أقل 5** أنواع بيتزا من حيث **الكمية المباعة**.

## 🛠️ الأدوات المستعملة ومسار البيانات

### 1. الأدوات والتقنيات

- **مصدر البيانات:** [Kaggle](https://www.kaggle.com) (مجموعة بيانات مبيعات البيتزا لعام 2015 - صيغة CSV)
- **استكشاف وتنظيف البيانات:** Microsoft Excel & Power Query
- **إدارة وقواعد البيانات:** PostgreSQL / SQL Server (استعلامات SQL)
- **تصوير البيانات والتحليل:** Power BI (معادلات DAX، لوحات تحكم تفاعلية)
- **إدارة النسخ:** Git & GitHub

---

### 2. مسار البيانات الشامل (Data Pipeline)

`[Raw CSV (Kaggle)]` ➡️ `[Excel / Power Query (EDA & Cleaning)]` ➡️ `[SQL Database (Schema Setup & Queries)]` ➡️ `[Power BI (Modeling, DAX & Visualization)]`

- **الخطوة 1: استكشاف وتنظيف البيانات (Excel & Power Query)**
  - إجراء استكشاف أولي للبيانات (EDA) لفهم هيكل البيانات وتوزيع الأعمدة.
  - استخدام Power Query للتنظيف الأولي، والتحقق من أنواع البيانات، وفحص القيم المفقودة، وتنسيق التواريخ والأوقات.

- **الخطوة 2: إعداد قاعدة البيانات وتنفيد الاستعلامات (SQL)**
  - إنشاء مخطط قاعدة بيانات (Schema) مطاق للبيانات المنظفة.
  - استيراد ملف CSV المعالج إلى جداول SQL.
  - كتابة استعلامات SQL متقدمة لاستخراج الرؤى التشغيلية، واختبار حسابات مؤشرات الأداء، والإجابة على أسئلة العمل الأساسية.

- **الخطوة 3: النمذجة وبناء لوحات التحكم (Power BI & Excel)**
  - استيراد البيانات إلى Power BI وإنشاء العلاقات بين الجداول.
  - إنشاء مقاييس DAX مخصصة لمؤشرات الأداء الرئيسية التفاعلية (Total Revenue, AOV, Total Pizzas Sold، وغيرها).
  - تصميم واجهة مستخدم تفاعلية وعصرية تعتمد على مبادئ تصميم 60-30-10 للتقارير التنفيذية.

## 📊 النتائج والرؤى التنفيذية

### 1. مؤشرات الأداء الرئيسية (KPIs)

- **إجمالي الإيرادات:** 817.86 ألف دولار تم تحقيقها خلال السنة المالية 2015.
- **إجمالي الطلبات:** 21,350 معاملة شراء منفصلة.
- **إجمالي البيتزا المباعة:** 49,574 قطعة بيتزا مباعة.
- **متوسط قيمة الطلب (AOV):** 38.31 دولار لكل معاملة في المتوسط.

### 2. الاتجاهات التشغيلية وساعات الذروة

- **أيام الذروة:** يسجل يوما **الجمعة** و**الخميس** أعلى حجم للطلبات ونشاط المبيعات، مما يحدد الأوقات التشغيلية التي تتطلب تجهيز طاقم المطبخ والمخزون بشكل مثالي.

### 3. تفضيلات المنتجات وتوزيع الفئات

- **الفئة الأكثر مبيعاً:** تتصدر فئة **Classic** الحصة السوقية من حيث إجمالي طلبات العملاء والمساهمة في الإيرادات.
- **الحجم المفضل:** يفضل العملاء بيتزا الحجم الكبير **Large (L)** بشكل كبير، حيث تمثل الجزء الأكبر من إجمالي حجم المبيعات.

### 4. أداء المنتجات (الأعلى والأقل)

- **الأعلى تحقيقاً للإيرادات:** برزت بيتزا **The Thai Chicken Pizza** كأعلى منتج تحقيقاً للإيرادات.
- **الأقل تحقيقاً للإيرادات:** سجلت بيتزا **The Brie Carre Pizza** أدنى أداء في الإيرادات، مما يشير إلى فرصة لتحسين قائمة الطعام أو إطلاق عروض خاصة أو استبدالها.

🚀 كيفية التشغيل والتكرار
إعداد قاعدة البيانات:

افتح أداة إدارة قواعد البيانات المفضل لديك (مثل PostgreSQL / SQL Server).
